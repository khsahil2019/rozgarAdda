ROZGAR ADDA - JOB POST API DOCUMENTATION

API Endpoint:
POST /api/emp/post-job
Authentication:
Authorization: Bearer {token}

IMPORTANT:
Employer can post jobs only when booking_status = approved.
If employer is pending/rejected, API should return:

{
"status": false,
"message": "Your account is awaiting admin approval."
}

---

## REQUIRED FIELDS

category_id          (integer)
role_id              (integer)
title                (string)
vacancy              (integer)
job_type             (enum)
work_location_type   (enum)
pay_type             (enum)
education_level      (string)
english_level        (enum)
experience_level     (string)
plan_id              (integer)

---

## ENUM VALUES

job_type:
full_time
part_time
both

work_location_type:
office
home
field

pay_type:
fixed
fixed_inc
inc_only

english_level:
none
basic
good

contact_preference:
self
other
none

shifts:
day
night
rotational
flexible

---

## LOCATION RULES

If work_location_type = office

Required Fields:

office_state_id
office_district_id
office_localite_id
office_address_line1
office_pincode

Optional:

office_address_line2

---

If work_location_type = field

Required Fields:

field_state_id
field_district_id
field_localite_id
field_address_line1
field_pincode

Optional:

field_address_line2

---

If work_location_type = home

No location fields required.

---

## SALARY RULES

If pay_type = fixed

min_salary
max_salary

---

If pay_type = fixed_inc

fixed_salary
avg_incentive

---

If pay_type = inc_only

estimated_incentive

---
